# Backend templates

Placeholders: `{Entity}` (PascalCase), `{entity}` (camelCase), `{Entities}` / `{entities}` (plural),
`{package}`, `{table}`, `{url}` (e.g. `customers`), `{Key}` / `{key}` / `{key_column}` /
`{key label}` (the unique natural-key field, e.g. `Email` / `email` / `email` / `email`).
Lines marked `// each field` repeat per field from the field spec, in spec order.
Sections marked *(if unique)* exist only when the entity has a unique field; repeat them per unique field.

Package: `com.example.dealership.{package}`. All files in one package (main and test).

## Migrations

`backend/src/main/resources/db/migration/V{n}__{table}.sql`

```sql
CREATE TABLE {table} (
    id         BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    first_name VARCHAR(100) NOT NULL,      -- each field, columns aligned
    nip        VARCHAR(10),
    CONSTRAINT uq_{table}_{key_column} UNIQUE ({key_column})
);
```

`V{n+1}__{table}_seed.sql`: 2–3 rows, every row valid against the Request validation and unique.

```sql
INSERT INTO {table} (first_name, nip) VALUES
    ('Jan', NULL),
    ('Anna', '5260250995');
```

## Entity

```java
package com.example.dealership.{package};

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Table;

@Entity
@Table(name = "{table}")
public class {Entity} {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 100)   // each field: mirror the SQL column
    private String firstName;

    protected {Entity}() {
    }

    public {Entity}(String firstName /* , every field except id, spec order */) {
        this.firstName = firstName;
    }

    public Long getId() {
        return id;
    }

    // each field: getter + setter, no other methods
    public String getFirstName() {
        return firstName;
    }

    public void setFirstName(String firstName) {
        this.firstName = firstName;
    }
}
```

`java.time.LocalDate` / `java.math.BigDecimal` imports go first (java.*), then a blank line,
then `jakarta.*`, as in `Vehicle.java`. Enum columns: `@Enumerated(EnumType.STRING)` above
`@Column(nullable = false, length = 20)`. Boolean: `@Column(nullable = false) private boolean x;`
with getter `isX()`.

## Request / Response

```java
public record {Entity}Request(
        @NotBlank
        @Size(max = 100)
        String firstName,

        @Size(max = 10)
        @Pattern(regexp = "[0-9]{10}", message = "must be exactly 10 digits")
        String nip
) {
}
```

One annotation per line, a blank line between components (see `VehicleRequest`).

*(if a unique field is case-insensitive, e.g. email)* the Request is the **only** place that
normalizes it, via a compact constructor; mapper, service and repository just use the value:

```java
public record {Entity}Request(
        @NotBlank
        @Email
        @Size(max = 255)
        String email
) {

    public {Entity}Request {
        email = email == null ? null : email.trim().toLowerCase(Locale.ROOT);
    }
}
```

```java
public record {Entity}Response(
        Long id,
        String firstName,
        String nip
) {
}
```

    private {Entity}Mapper() {
    }

## Repository

```java
public interface {Entity}Repository extends JpaRepository<{Entity}, Long> {

    boolean existsBy{Key}(String {key});                 // (if unique) plain query, also for emails

    boolean existsBy{Key}AndIdNot(String {key}, Long id);
}
```

No unique field → empty interface body `{ }` on separate lines like a normal interface.

## Service

```java
@Service
@Transactional(readOnly = true)
public class {Entity}Service {

    private final {Entity}Repository {entity}Repository;

    public {Entity}Service({Entity}Repository {entity}Repository) {
        this.{entity}Repository = {entity}Repository;
    }

    public List<{Entity}Response> findAll() {
        return {entity}Repository.findAll(Sort.by("id")).stream()
                .map({Entity}Mapper::toResponse)
                .toList();
    }

    public {Entity}Response findById(Long id) {
        return {Entity}Mapper.toResponse(get{Entity}(id));
    }

    @Transactional
    public {Entity}Response create({Entity}Request request) {
        if ({entity}Repository.existsBy{Key}(request.{key}())) {          // (if unique)
            throw {key}AlreadyExists(request.{key}());
        }
        {Entity} {entity} = {entity}Repository.save({Entity}Mapper.toEntity(request));
        return {Entity}Mapper.toResponse({entity});
    }

    @Transactional
    public {Entity}Response update(Long id, {Entity}Request request) {
        {Entity} {entity} = get{Entity}(id);
        if ({entity}Repository.existsBy{Key}AndIdNot(request.{key}(), id)) {   // (if unique)
            throw {key}AlreadyExists(request.{key}());
        }
        {Entity}Mapper.updateEntity({entity}, request);
        return {Entity}Mapper.toResponse({entity}Repository.save({entity}));
    }

    @Transactional
    public void delete(Long id) {
        {entity}Repository.delete(get{Entity}(id));
    }

    private {Entity} get{Entity}(Long id) {
        return {entity}Repository.findById(id)
                .orElseThrow(() -> new NotFoundException("{Entity} with id " + id + " not found"));
    }

    private static ConflictException {key}AlreadyExists(String {key}) {   // (if unique)
        return new ConflictException("{Entity} with {key label} " + {key} + " already exists");
    }
}
```

Optional unique field: guard with `request.{key}() != null && ...`.

## Test checklist

### `{Entity}ControllerTest` — `@WebMvcTest({Entity}Controller.class)`, `@MockitoBean {Entity}Service`

Constants: natural-key constant (e.g. `EMAIL`), `VALID_BODY` text block with every field (optional
ones filled), helpers `invalidBody()` and `response()`. Method names and assertions as in
`VehicleControllerTest`:

| Test | Asserts |
| --- | --- |
| `findAllReturns{Entities}` | 200, length 1, id, key field, one field of each kind (enum, date, boolean…) |
| `findByIdReturns{Entity}` | 200, key field |
| `findByIdReturnsNotFoundProblemWhen{Entity}DoesNotExist` | 404, `application/problem+json`, `status`, `detail` |
| `createReturnsCreated{Entity}` | 201, `Location` = `http://localhost/api/{url}/1`, id |
| `createReturnsBadRequestProblemWithFieldErrorsWhenRequestIsInvalid` | 400, `detail` = `Validation failed`, exact `errors.length()`, each `field` (sorted alphabetically) and at least one `message`; `verifyNoInteractions(service)` |
| `createReturnsEnglishValidationMessagesWhenAcceptLanguageIsPolish` | `Accept-Language: pl`, blank required field → `must not be blank` |
| `createReturnsBadRequestProblemWithFieldErrorWhen{EnumField}IsUnknown` *(per enum)* | `must be one of: A, B, C` |
| `createReturnsBadRequestProblemWithFieldErrorWhenValueHasWrongType` | number/date/boolean field given `"text"` (only strings? give a string field `{}`) → `has an invalid value` |
| `createReturnsBadRequestProblemWhenBodyIsNotJson` | `{ not json` → field `null`, `request body must be valid JSON` |
| `createReturnsConflictProblemWhen{Key}AlreadyExists` *(if unique)* | 409, detail from `ConflictException` |
| `createReturnsConflictProblemWhenDatabaseConstraintIsViolated` | `DataIntegrityViolationException("uq_{table}_{key_column}")` → 409 `Request conflicts with existing data` |
| `updateReturnsUpdated{Entity}` | 200 |
| `updateReturnsNotFoundProblemWhen{Entity}DoesNotExist` | 404 |
| `updateReturnsBadRequestProblemWithFieldErrorsWhenRequestIsInvalid` | 400 fields, no interactions |
| `updateReturnsConflictProblemWhen{Key}AlreadyExists` *(if unique)* | 409 |
| `deleteReturnsNoContent` | 204, `verify(service).delete(1L)` |
| `deleteReturnsNotFoundProblemWhen{Entity}DoesNotExist` | 404 via `doThrow` |

`invalidBody()`: break 3 fields of different kinds so that each produces **exactly one** error
(a blank required string without a pattern, a pattern/email violation, a range violation, a missing
required field). Errors are sorted by field name, then message — assert in that order.

### `{Entity}ServiceTest` — `@ExtendWith(MockitoExtension.class)`, `@Mock` repository, `@InjectMocks` service

`findAllReturnsMapped{Entities}` (verifies `Sort.by("id")`), `findByIdThrowsNotFoundWhen{Entity}DoesNotExist`
(exact message), `createSaves{Entity}` (save answers its argument; assert mapped fields),
`createThrowsConflictWhen{Key}AlreadyExists` (exact message, `never()).save(any())`),
`updateChangesExisting{Entity}`, `updateThrowsConflictWhen{Key}BelongsToAnother{Entity}`,
`updateThrowsNotFoundWhen{Entity}DoesNotExist`, `deleteRemovesExisting{Entity}`,
`deleteThrowsNotFoundWhen{Entity}DoesNotExist`. Helpers `{entity}(key)` and `request(key)`,
constants `KEY` / `OTHER_KEY`. Optional unique field: add a test that `null` skips the check.
Normalized field: `createStoresNormalized{Key}` (request with e.g. ` Jan.Kowalski@Example.COM `,
assert the repository check, the saved entity and the 409 message all use the lowercase trimmed value).
Custom business rules: one test per rule and per boundary.

### `{Entity}RepositoryTest` — `@DataJpaTest`, `TestEntityManager`

Use key values that differ from the seed data. `existsBy{Key}AndIdNotFinds{Key}OfAnother{Entity}`
(two saved rows, true/false/unknown key) and
`saveStores{Entity}ThatCanBeReadBack` (flush, clear, `findById`, `isNotSameAs`, every field).
